Funciones principales

!DOCTYPE html: Nos dará el tipo de archivo con el que estaremos trabajando

html: Es como la llave que abré todo lo que contendrá nuestro código

head: Todo lo que se mostrará en la parte superior.

body: es el cuerpo, tendrá todas las cosas que se mostrarán en la página

h1 al h6: Tipos de títulos, siendo h1 el más grande y h6 más chico.

p: párrafo

Inserción de links

a: Se utiliza para crear enlace.

href: Es un atributo de la etiqueta "a" que especifica la URL del enlace que queremos Luego del href se pone el texto a mostrar donde clickaremos en el y nos mandará a la página, como un hipervínculo.

Inserción de imágenes

img: será la etiqueta de para insertar la imagen.

src: donde se pone la dirección de imagen

alt: texto alternativo si la imagen no pudo ser cargada.

width: ancho de la imagen

height: alto de la imagen

Inserción de imágenes con link

Lo único que cambia es que antes de la etiqueta "img" se insertará la imagen deseada.

target: especifica donde se muestra el link deseado.

Los distintos tipos de target son:

_blank: Abre en una nueva ventana o pestaña del navegador.

_self: Abre en la misma ventana donde se encuentra la imagen.Valor predeterminado si no se especifica nada.

_parent: Se debe abrir en el marco padre de iframe donde se encuentra el enlace.

_top: Abre el enlace en la ventana completa del navegador, eliminando todos los marcos.

Iframe y Marcos

linea del codigo: iframe src="iframe_content.html" width="600" height="400"

Los marcos (Frames) Son secciones de una ventana del navegador que pueden mostrar diferentes documentos HTML simultaneamente. Pero esto quedó obsoleto para HTML5 que es lo que usamos nosotros. Por otro lado los Iframes (Inline Frames) son elementos de HTML que dejan incrustar un documento HTML dentro de otro documento HTML. Se crean usando la etiqueta "iframe".Los iframes permiten entonces mostrar contenido de una página web dentro de otra sin recargar la página principal. Un ejemplo de uso se verá más adelante.
